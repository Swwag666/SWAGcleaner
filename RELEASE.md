# SWAGcleaner - релиз v1.0.0

Простая памятка. Без жаргона. Что это, как запустить, как собрать, как проверить.

## Что это

Локальный чистильщик Windows. Убирает мусор, находит дубликаты, отключает лишние твики
системы. Работает целиком на твоей машине: ноль сети, ноль аккаунтов, ноль слежки.
Ничего не удаляется и не отключается без твоего подтверждения.

## Как запустить (самое простое)

1. Возьми готовый файл: `dist/SWAGcleaner.exe`.
2. Двойной клик. Всё.

Если Windows спросит «защитник не знает издателя» - нажми «Подробнее» → «Выполнить в любом
случае». Это потому, что exe не подписан дорогим сертификатом, а не потому, что он опасный.

## Как собрать из исходников

```bash
venv\Scripts\python.exe -m PyInstaller --noconfirm --distpath dist --workpath build SWAGcleaner.spec
```

Готовый файл появится в `dist/SWAGcleaner.exe`.

## Как прогнать тесты

```bash
venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
```

Сейчас: **398 тестов, все зелёные.** Плюс 54 теста Rust-ядра:
`cd rust/swagscan && cargo test`.

## Что нового в этой версии

- **Четыре темы**: тёмная, светлая, монохром, «Числовая» (тёмно-синяя с золотом).
  Плюс три акцентных цвета (синий / фиолет / изумруд). Переключается в настройках.
- **Два героя**: пиксельная Клинни во всех темах, и новый персонаж - только в теме
  «Числовая», с мягким свечением по контуру.
- **Прокачанный интерфейс**: скруглённые углы, объём у панелей (светлая верхняя кромка),
  частицы при чистке, тряска экрана при панике, плавные анимации.
- **Подчищены тормоза**: древовидная карта не пересчитывается на каждый кадр, спрайты
  кешируются по размеру, частицы облегчены.
- **Чистка вырезки героя**: фон режется нейросетью (isnet), дырки в ногах залиты.

## Что надо знать перед раздачей людям

1. **Права администратора.** Чистка и твики просят UAC. Программа объясняет, зачем, а не
   просто дёргает системное окно.
2. **Удаление в корзину** - всё, что можно вернуть. Мимо корзины - только регенерируемый
   мусор (temp, кеши, логи), и он по умолчанию НЕ отмечен: его выбирают руками.
3. **Никогда не трогается**: WinSxS, точки восстановления, pagefile, файлы установленных
   программ, симлинки, личные файлы без явной галочки.
4. **Откат твиков.** Каждое отключение снимает снапшот; кнопка «Вернуть» возвращает
   прежнее состояние. Снапшот переживает перезапуск.
5. **Перед публичным релизом** всё равно прогони разок на чистой VM: скан → чисти мелкую
   категорию → твик вкл/выкл → верни. Юнит-тесты не заменяют живой дымового теста.
